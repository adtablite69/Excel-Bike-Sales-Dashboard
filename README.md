# 🚴 Bike Sales Dashboard | Excel Data Analysis Project

## 📌 Project Overview

This project focuses on analyzing customer data to understand bike purchasing behavior and identify key trends that influence customer purchasing decisions.

The analysis was performed using **Microsoft Excel**, including data cleaning, data transformation, Pivot Tables, Pivot Charts, and an interactive dashboard.

The dataset contains **1,000+ customer records** with demographic, financial, and lifestyle information.

---

## 🎯 Project Objective

The main objective of this project is to analyze customer data and identify factors that influence bike purchases.

Key questions explored include:

* Does customer income influence bike purchases?
* Which age groups are more likely to purchase bikes?
* How does commute distance affect purchasing decisions?
* What is the relationship between marital status and bike purchases?
* Which customer segments are more likely to purchase a bike?
